agent tui 0.4.2 | local embedded | agent main> explain sshSSH, or Secure Shell, is a protocol for logging in to another computer over a network you do not trust and working on it as if you were at its keyboard.Everything that passes between the two machines (commands, output, files) is encrypted before it leaves and decrypted only on the other end.### 1. What is it used for?- Remote administration: open a shell on a server to install packages, edit configs, or read logs.- File transfer: scp and sftp ride on top of SSH, so copies inherit the same protection.- Port forwarding: wrap a plaintext service, like a database port, inside the tunnel.### 2. Where does the security come from?SSH replaced Telnet, which sent passwords in the clear. It layers three kinds of cryptography:- Key exchange: both sides derive a fresh session key; an observer never sees it.- Symmetric encryption: that key encrypts the traffic, fast enough for interactive use.- Integrity checks: every packet carries a MAC, so tampering is detected and the connection drops.### 3. Keys instead of passwordsPut your public key on the server in authorized_keys. Your private key never leaves your machine, so there is no password to phish, and access is revoked by deleting one line.### 4. A minimal config```# ~/.ssh/configHost prod    HostName 203.0.113.7    User admin    IdentityFile ~/.ssh/id_ed25519    ForwardAgent no```Then ssh prod connects. On the first connection SSH shows the host fingerprint and asks whether to trust it.### 5.
