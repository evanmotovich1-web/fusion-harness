# Partial local CRM operation layer

```sh
python3 -B research/ai-saas-100/cases/003/tests/run.py
```

Python standard library only. `workflow.py` accepts explicit structured actions and synthetic contacts. It previews contact updates and duplicate groups, validates fields and preserves note text as inert data. The input remains unchanged. Nothing is persisted or sent to a CRM, browser, LinkedIn, email service or any network endpoint.

All 20 local regression assertions passed. Fifteen valid cases produce only previews. Natural-language interpretation, real model inference, integration execution and generic-model comparison are unavailable. A structured local preview is not a reproduction of the advertised conversational sales agent. The pilot remains incomplete.

Fixtures were frozen before implementation and are builder-visible, not held out. Review must inspect exact scope and obtain real authorized inference plus an approved synthetic integration evaluator before acceptance. Pricing-request versus credit language and differing integration counts are recorded without silently reconciling them in ../dossier.json.
